Code standards for my projects

Python code should be linted using ruff
Tests should be implemented with pytest
Standard MIT open source licence should be applied
Numpy should be imported as 'np'. matplotlib.pyplot as 'plt'
Avoid the word 'test' in naming of variables during development (e.g. 'testmatrix' etc).
Style for documentation should be succinct and factual, not gushing or florid- think dour Scots rather than effusive American
